# Spatial Context-Menu Tabs — v0.3 Checkpoint

Status: **exploratory / non-actionable**

This version preserves the current five-pop-out aesthetic checkpoint before the next interaction change.

## What v0.3 preserves

The root/right-click menu exposes five initial pop-out families for visual testing:

- Move to…
- Copy to…
- Share with…
- Organize…
- Versions…

Each family opens as its own first-level pop-out while deeper navigation continues to use the alternating spatial pattern:

```
root → submenu ← deeper submenu → deeper submenu ...
```

The dedicated vertical-tab area remains to the left of the root menu so tabs never overlap menu panels.

The prior starred-arrangement concept remains part of this checkpoint: user-selected arrangements may be preserved as explicit quick-access states rather than automatic recent-history entries.

## Why this checkpoint exists

v0.3 records the five-pop-out visual test as a stable comparison point before experimenting with a new model in which every initial pop-out receives its own vertical slice and the slice rail temporarily reorganizes into active/rest rows.

This is not the final interaction specification.
